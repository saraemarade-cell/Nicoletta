Custom Post Types
Progetto: Sito vetrina professionale con blog, podcast, eventi e form di contatto. Nessun e-commerce nella versione attuale. Il sito HTML/CSS/JS statico di riferimento è già completo — il lavoro di sviluppo consiste nel riprodurre fedelmente il design in Elementor, configurare i CPT, e collegare i form.
Tema base consigliato: Hello Elementor (tema ufficiale di Elementor, leggero e privo di stili predefiniti). Alternativa: Astra con kit blank.
⚙️
Stack tecnologico
Page Builder
Elementor Pro
Indispensabile per replicare il layout preciso del prototipo. Richiede Pro per Theme Builder (header/footer custom), popup, e widget Loop Grid per i CPT.
Tema
Hello Elementor
Tema ufficiale Elementor. Zero stili predefiniti, massima compatibilità. Non modificare il tema — tutto il design va in Elementor.
CSS / Token
Global CSS in Elementor
I custom properties CSS del sito (--c-green-700, --c-peach, ecc.) vanno trascritti come Global Colors e Global Fonts in Elementor → Global Settings.
Animazioni
Elementor Scroll Effects + JS custom
Le animazioni .reveal / .visible (IntersectionObserver) vanno ricreate con Elementor Scroll Effects oppure mantenendo il file js/main.js come script custom.
Hosting
Server PHP 8.1+ / LiteSpeed
Preferibilmente hosting con LiteSpeed (LiteSpeed Cache gratuito) o Nginx. PHP 8.1+, MySQL 8.0+, SSL attivo. WP Rocket funziona su qualsiasi stack.
Deploy SEO
Yoast SEO
I meta tag OG, canonical, Twitter Card e JSON-LD già implementati nel prototipo HTML vanno riconfiggurare in Yoast. Verificare che i valori combacino prima del go-live.

Note tecniche per pagina
🏠 Homepageindex.html
Alta priorità›
  • Hero slider: Elementor non ha uno slider built-in in Pro. Usare il widget Slides di Elementor Pro oppure installare Swiper JS via script custom. Il JS autoplay è già implementato nel prototipo — può essere riutilizzato come Custom JS in Elementor.
  • Contatore "+3.000": Elementor Pro ha il widget Counter con animazione al scroll. Configurare valore, durata e suffisso "h di insegnamento".
  • Foto geometrica clip-path: clip-path: polygon(0 0, 86% 0, 100% 14%, 100% 100%, 14% 100%, 0 86%) — applicare come CSS custom sul widget Image in Elementor (Custom CSS nel pannello Advanced).
  • Strip certificazioni: Layout flex con divisori verticali. Creare con widget Inner Section o Flexbox Container in Elementor. I badge (immagini .webp) vanno caricati in Media Library.
  • Newsletter form: Widget WPForms + Brevo/Mailchimp integration. Creare il form in WPForms, collegare all'account newsletter.
👤 Chi sonochi-sono.html
Media›
  • Certificazioni layout orizzontale: Layout a 5 colonne (auto 1px auto 1px 1fr) con CSS Grid custom. Richede Custom CSS sul Container o un widget HTML per il blocco cert-compact. Non riproducibile nativamente con widget Elementor standard.
  • Icona formazione (graduation cap): SVG inline nel box — caricare come SVG Custom Icon set in Elementor o usare widget Icon con libreria custom (Lucide/Iconify).
  • Tags (E-RYT, YACEP, ICF): Widget Text con styled span. Alternativa: widget Button senza link, stile pill.
  • Sezione percorsi: 3 card con immagine, categoria, titolo, testo, link. Usare Loop Grid Elementor con CPT custom o con Posts standard. Layout replica già esistente nelle pagine servizio.
🧘 Yoga + Coaching (simili)yoga.html / coaching.html
Media›
  • Target section (dark green): Background var(--c-green-700) = #1F3220. Impostare come sezione con colore sfondo custom. Il testo usa opacità ridotta — impostare color con alpha in Elementor o CSS custom.
  • Steps numerati (01, 02, 03): Widget personalizzato o Inner Section con 3 colonne, separatori verticali, numerazione con widget Heading. CSS per il numero grande (font-size: clamp(2.8rem, 4vw, 3.8rem)) via Custom CSS.
  • FAQ accordion (solo Coaching): Widget Accordion di Elementor Pro, configurare domande e risposte. Testare animazione open/close. Il JS custom del prototipo non è necessario con Elementor Accordion.
  • CTA terracotta (Coaching): Background #9F644A — impostare come sezione con colore custom.
🏢 Benessere Aziendalebenessere-aziendale.html
Alta priorità›
  • Hero dark con foto sfondo: Sezione con background image + overlay scuro (rgba(0,0,0,0.55)). La navbar diventa trasparente su questa pagina — configurare in Elementor Theme Builder con condizione di pagina.
  • Gradiente "Come iniziare": linear-gradient(135deg, #4a5a4b, #9F644A) — impostare come sfondo CSS custom sulla sezione (background: linear-gradient(135deg,...); in Custom CSS sezione).
  • Form inline nella CTA: WPForms widget inserito direttamente nella colonna destra della sezione CTA. Layout 2-col: testo sx + form dx. Stile del form va allineato alla dark section — usare il tema del form "Transparent" o CSS custom per rimuovere sfondi bianchi.
  • Navigazione dark: Header con logo bianco e menu chiaro — usare Elementor Theme Builder con condizione questa pagina per applicare header alternativo dark, oppure usare sticky header con cambio colore al scroll.
📅 Eventieventi.html
Media›
  • CPT "Evento": Registrare con Custom Post Type UI. Campi ACF: data_evento (Date Picker), luogo (Text), tipo (Select: Retreat / Workshop / Lezione), prezzo (Number), link_iscrizione (URL), sold_out (True/False).
  • Evento in evidenza: Post singolo selezionato manualmente — usare un campo ACF booleano in_evidenza e filtrare la query Loop Grid per questo campo. Alternativa: usare "Evento in evidenza" come pagina statica Elementor.
  • Lista eventi: Loop Grid Elementor con template card custom (data + tipo + titolo + luogo + CTA). Ordinare per data_evento ASC. Filtrare gli eventi passati con query personalizzata (meta_query su data).
🎙 Podcastpodcast.html
Bassa›
  • Opzione A (semplice): Embed diretto da Spotify o Anchor — usare widget HTML in Elementor con il codice embed della piattaforma. Nessun plugin necessario.
  • Opzione B (completo): Plugin Seriously Simple Podcasting — gestisce feed RSS, lista episodi, player integrato. Compatibile con Apple Podcasts, Spotify, Google Podcasts. Richiede configurazione RSS.
  • CPT manuale: Se si vuole lista episodi personalizzata senza plugin podcast, creare CPT "Episodio" con ACF: audio_url, durata, numero_episodio, stagione. Loop Grid con template custom.
  • Link piattaforme: 3 bottoni (Spotify, Apple Podcasts, Google Podcasts) — widget Button Elementor con link URL esterno e icona SVG custom.
💻
Codice custom necessario
Attenzione: Questi elementi del design HTML statico non sono riproducibili nativamente con widget Elementor standard e richiedono Custom CSS / Custom JS.
Custom CSS globale
CSS Variables (Design Tokens)
I custom properties --c-green-700, --c-peach, --space-2xl ecc. vanno aggiunti come Custom CSS in Elementor → Site Settings → Custom CSS (o nel child theme style.css). Senza questi token, tutti i CSS custom delle sezioni falliscono.
JS — Animazioni scroll
IntersectionObserver (.reveal)
Il file js/main.js del prototipo contiene l'observer per le classi .reveal → .visible. Va incollato in Elementor → Site Settings → Custom Code (prima del tag </body>). Alternativa: usare Elementor Scroll Effects su ogni widget (meno efficiente).
CSS — Forma geometrica
clip-path ottagono sulle foto
Su ogni widget Image dove va la forma: Advanced → Custom CSS → selector .elementor-widget-image img { clip-path: polygon(0 0, 86% 0, 100% 14%, 100% 100%, 14% 100%, 0 86%); }. Applicare su ogni immagine nelle pagine Yoga, Coaching, Chi sono, Home.
JS — Info bar
Banner dismissibile in cima
Il banner "Nuovo retreat in programma" con bottone ✕ può essere ricreato con Elementor Popup (tipo Notification Bar) oppure mantenendo il blocco HTML custom con il JS di chiusura dal prototipo, incollato in un widget HTML.
CSS — Numerazione grande
Numeri steps (01, 02, 03)
La tipografia grande per i numeri (clamp(2.8rem, 4vw, 3.8rem) in verde) richiede Custom CSS sul widget Heading: selector h2 { font-size: clamp(2.8rem,4vw,3.8rem); color: var(--c-green-700); }
CSS — Certificazioni
Layout orizzontale compatto
La sezione certificazioni con 5 colonne (badge | sep | numero | sep | lista) richiede un Container Elementor con CSS Grid custom: display:grid; grid-template-columns: auto 1px auto 1px 1fr; gap: 0 3.5rem; via Custom CSS sul Container.

Checklist pre-deploy

SEO & Meta

  • □ Yoast configurato per ogni pagina (title, description, OG image)
  • □ Sitemap XML generata e verificata in Google Search Console
  • □ robots.txt configurato (Yoast lo genera automaticamente)
  • □ JSON-LD Person schema verificato con Google Rich Results Test
  • □ Canonical URL corretti per ogni pagina

Performance

  • □Lighthouse score > 85 su mobile
  • □Tutte le immagini in formato .webp con dimensioni ottimizzate
  • □WP Rocket / LiteSpeed Cache attivo
  • □Lazy load immagini attivo

Funzionalità

  • □Form di contatto testati — email ricevuta
  • □WP Mail SMTP configurato e testato
  • □SSL attivo, redirect HTTP → HTTPS
  • □Mobile responsive testato su iPhone e Android
  • □Menu hamburger mobile funzionante

Contenuti

  • □Testi definitivi sostituiti ai placeholder
  • □Immagini reali caricate (lafondatrice.webp, yoga.webp, ecc.)
  • □Logo in formato .webp + SVG nelle due varianti (bianco/nero)
